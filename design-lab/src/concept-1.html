01Idea and what it borrows

A field kit is a set of cards. You pick one, do the work, and file the result. The brand is the index.

Fieldwork is named after how people learn in the field: go out, try it on real material, write down what happened. The identity makes that physical. Each exercise is a numbered field card with a metadata table (Filed, Takes, Needs). Pages are built from full-width colour chapters, one job per colour. Every card carries its own piece of field: a unique cartographic contour map generated from the card's number, so No. 01 and No. 02 never look alike, and the work looks like an expedition, not a course catalogue.

For businesses the same system runs in a calmer register: more ink, fewer colours, the field in one tone, and a Problem / Practice / Result structure borrowed from Anveril's approach to enterprise content.

05Wordmark and symbol
Fieldwrk
Fieldwrk
Fieldwrk

The mark is the summit: the nested rings around the highest point of one of our generated fields (seed 18). It is the "o" in Fieldwork and also stands alone as the symbol, so the name and the artwork system share one shape. It is organic and slightly irregular, so it does not read as a stock target icon. It drops to three rings at 40px and two at 20px for favicons. The wordmark is Gloock, set tight, with the core of the summit in vermilion. In use, the footer scales the wordmark to the full width of the page (a Vide Infra and Anveril idea): one monumental placement, never repeated.

11Strengths, weaknesses, risks

Strengths

  • An interface that is a system of named, numbered objects, as the best references do.
  • The generated field is original, meaningful for the name, endlessly reusable (covers, social, slides, video) and costs nothing to produce.
  • Colour carries the learning grammar.
  • One system with two registers: expressive for learners, calm for business.

Weaknesses

  • Close in spirit to Anwulika's archive language. Needs our own palette, type, and the field to keep it distinct.
  • Gloock has one weight, so hierarchy must come from size and colour.
  • Tilt, tape and torn edges need discipline to avoid looking like scrapbooking.

Risks

  • Generative contours must look hand-finished: tune levels and line weights per colourway.
  • Heavy colour blocks on small screens need testing for fatigue and contrast.
  • Not yet tested with users.
